# NOVA — Unity Game Developer Portfolio

A cinematic dark sci-fi game developer portfolio built with plain HTML, CSS and JavaScript.

## Included
- Glassmorphism navigation and UI panels
- Animated starfield background
- CSS 3D-inspired Unity core / orbital scene
- Scroll reveal animations
- Interactive 3D tilt on project cards
- Animated progress bars, radar, marquee and floating UI
- Responsive layout for desktop/tablet/mobile
- Reduced-motion accessibility fallback

## Customize
1. Open `index.html`.
2. Replace `NOVA`, project names, stats, skill percentages and email.
3. Replace the CSS-made project artwork with real screenshots later if desired.
4. Upload the folder to Netlify, Vercel, GitHub Pages, or any static host.

No build step is required.
